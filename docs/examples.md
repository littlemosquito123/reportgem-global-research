# 示例问法

在任何已接入 ReportGem MCP 的客户端里直接用自然语言提问，客户端会自动调用对应工具。

## 全球研报
- 高盛最近一周关于英伟达的观点，给我来源页码
- 对比花旗和摩根士丹利对 2026 年美联储降息的预测
- 摩根大通最新的中国互联网行业研报说了什么，用中文总结
- 瑞银和野村对日本央行加息的看法有什么分歧
- 列出本周巴克莱发布的欧洲银行业研报标题

## 图表
- 找一张显示全球 AI 服务器出货量预测的图，并告诉我出自哪份研报
- 有没有研报里的表格对比了各大云厂商 2026 年资本开支

## 公告与会议纪要
- 台积电最近一次业绩会上管理层怎么谈先进制程产能
- 宁德时代最近的调研纪要里提到海外产能了吗
- 苹果最新 10-K 里关于中国市场风险的表述

## 原文核对
- 把上一条结果里第 2 个来源的第 3、4 页原文读给我（get_evidence 支持按页连续阅读）

## 提示
- 问题越具体（机构、公司、时间段），返回越准，消耗的积分也越少。
- 先用检索看标题和来源，再对需要的来源取原文，可以节省积分。
